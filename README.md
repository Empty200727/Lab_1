# Лабораторная работа № 1. Введение в Python

Дисциплина «Теория алгоритмов», 3 курс.

Проект содержит решения 11 стартовых задач на Python (строки, списки, кортежи,
словари, множества), общий модуль запуска `main.py` и набор автотестов на `pytest`.

## Содержимое

```text
Lab_1/
├── main.py              # общий запуск заданий (CLI)
├── requirements.txt     # зависимости для тестов
├── REPORT.md            # отчёт по работе
├── python_lab_01/       # модули-задания 00–10
└── tests/
    ├── conftest.py      # фикстура загрузки модулей
    └── test_tasks.py    # тесты
```

| № | Модуль | Что делает |
|---|---|---|
| 00 | `00_distance.py` | таблица расстояний между городами (`itertools.combinations`, `math.hypot`) |
| 01 | `01_circle.py` | площадь круга, проверка попадания точки в круг |
| 02 | `02_operations.py` | выражение из чисел 1–5, равное 25 |
| 03 | `03_favorite_movies.py` | выбор фильмов из строки срезами |
| 04 | `04_my_family.py` | рост отца и суммарный рост семьи |
| 05 | `05_zoo.py` | вставка, добавление, удаление в списке животных |
| 06 | `06_songs_list.py` | длительность песен из списка и из словаря |
| 07 | `07_secret.py` | расшифровка фразы набором срезов `slice` |
| 08 | `08_garden.py` | объединение, пересечение и разность множеств |
| 09 | `09_shopping.py` | два самых дешёвых магазина для каждой сладости |
| 10 | `10_store.py` | количество и стоимость товаров на складе |

## Подготовка окружения

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py           # все задания
python main.py 0 5 10    # выбранные задания
python main.py --list    # список заданий
python python_lab_01/07_secret.py   # одно задание напрямую
```

## Тесты

```bash
python -m pytest -v
```
