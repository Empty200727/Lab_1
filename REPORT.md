#### 2.2.1. 00_distance.py – таблица расстояний между городами

Пары городов перебираются функцией `itertools.combinations`, поэтому каждое
расстояние считается ровно один раз и сразу записывается в обе стороны таблицы.
Длина отрезка вычисляется через `math.hypot`, что эквивалентно формуле
√((x₁−x₂)² + (y₁−y₂)²).

```python
def segment_length(start, end):
    return hypot(end[0] - start[0], end[1] - start[1])


def build_distance_table(coords):
    table = {city: {} for city in coords}
    for first, second in combinations(coords, 2):
        length = segment_length(coords[first], coords[second])
        table[first][second] = length
        table[second][first] = length
    return table
```

#### 2.2.2. 01_circle.py – площадь круга и точки

Площадь считается по формуле S = πr² при π = 3.1415926 и округляется до
4 знаков функцией `round()`. Для проверки точки сравниваются квадраты: точка
(x, y) принадлежит кругу, если x² + y² ≤ r². Такой способ не требует извлечения
корня и не даёт погрешностей округления.

```python
def circle_area(r, pi=PI):
    return pi * r * r


def point_in_circle(point, r):
    x, y = point
    return x * x + y * y <= r * r
```

#### 2.2.5. 04_my_family.py – рост членов семьи

def height_of(heights, member):
    for name, value in heights:
        if name == member:
            return value
    raise KeyError(member)

    total = 0
    for _, value in heights:
        total += value
    return total

#### 2.2.6. 05_zoo.py – список животных

Медведь вставлен присваиванием пустому срезу `cages[1:1]`, птицы добавлены

```python
def zoo_steps(animals, new_birds):
    cages = list(animals)
    steps = []

    cages[1:1] = ['bear']
    steps.append(list(cages))

    cages.extend(new_birds)
    steps.append(list(cages))

    del cages[cages.index('elephant')]
    steps.append(list(cages))

    return steps


def cage_of(cages, animal):
    return cages.index(animal) + 1
```

#### 2.2.10. 09_shopping.py – самые дешёвые магазины

По условию словарь `sweets` заполнен вручную. Чтобы исключить ошибку при ручном
выборе, добавлена функция `cheapest_offers()`, которая собирает все предложения
по товарам и сортирует их по цене. Совпадение двух словарей проверяется в тесте.

```python
def cheapest_offers(all_shops, limit=2):
    offers = {}
    for shop_name, products in all_shops.items():
        for product in products:
            offers.setdefault(product['name'], []).append(
                {'shop': shop_name, 'price': product['price']}
            )
    return {
        name: sorted(items, key=lambda offer: offer['price'])[:limit]
        for name, items in offers.items()
    }
```

#### 2.2.11. 10_store.py – товары на складе

Функция `batch_totals()` по списку партий возвращает кортеж
(количество, стоимость). Функция `stock_report()` проходит по словарю `goods`,
по коду находит партии в `store` и формирует сводку.

```python
def batch_totals(batches):
    count = sum(batch['quantity'] for batch in batches)
    cost = sum(batch['quantity'] * batch['price'] for batch in batches)
    return count, cost


def stock_report(names, warehouse):
    return {name: batch_totals(warehouse[code]) for name, code in names.items()}
```

### 2.3. Функции run() и общий модуль запуска

Для уровня Medium каждый модуль разделён на «вычислительную» часть и функцию
`run()`, которая только печатает результаты. Вызов `run()` стоит под условием
`if __name__ == '__main__':`, поэтому при импорте модуль ничего не выводит, а
при прямом запуске файла работает как раньше.

Имена файлов начинаются с цифр (`00_distance` и т.д.), а идентификатор в
Python не может начинаться с цифры, поэтому инструкция `import` для них
неприменима. В `main.py` модули загружаются функцией
`importlib.import_module()`, принимающей имя строкой. Список заданий не
прописан вручную: он строится функцией `pkgutil.iter_modules()` по содержимому
пакета. Через модуль `argparse` можно указать номера нужных заданий или
вывести их список.

```python
def discover_tasks():
    names = [info.name for info in pkgutil.iter_modules(python_lab_01.__path__)]
    return sorted(name for name in names if name[:2].isdigit())


def load_task(name):
    return importlib.import_module(f'{PACKAGE}.{name}')


def main(argv=None):
    args = parse_args(argv)
    tasks = discover_tasks()

    if args.list:
        print('\n'.join(tasks))
        return

    for name in select_tasks(tasks, args.numbers):
        print(f'----- {name} -----')
        load_task(name).run()
        print()
```

Таким образом, `main.py` использует логику всех 11 заданий, а при добавлении
нового модуля в пакет он подхватится автоматически.

### 2.4. Тестирование с pytest

Для уровня Well-done подключён `pytest`. Тесты находятся в каталоге `tests/`:

- `conftest.py` – добавляет корень проекта в `sys.path` и объявляет фикстуру
  `task`, которая загружает модуль задания по имени;
- `test_tasks.py` – сами тесты.

Для однотипных проверок применён декоратор `@pytest.mark.parametrize`: одна
функция теста запускается с несколькими наборами входных данных (например,
четыре точки для проверки круга и четыре товара склада). Вещественные значения
сравниваются через `pytest.approx()`. Отдельно проверено, что `main.py`
находит все 11 модулей и корректно запускает выбранное задание (вывод
перехватывается фикстурой `capsys`).

```python
@pytest.mark.parametrize('point, expected', [
    ((23, 34), True),
    ((30, 30), False),
    ((0, 42), True),
    ((-42, 1), False),
])
def test_point_in_circle(task, point, expected):
    assert task('01_circle').point_in_circle(point, 42) is expected


def test_sweets_match_automatic_choice(task):
    module = task('09_shopping')

    assert module.sweets == module.cheapest_offers(module.shops)
```

## 3. Памятка по командам Git

| Команда | Назначение |
|---|---|
| `git clone <адрес>` | получить локальную копию удалённого репозитория |
| `git status` | посмотреть изменённые, новые и проиндексированные файлы |
| `git switch -c lab1` | создать ветку `lab1` и сразу перейти в неё |
| `git branch` | список локальных веток, текущая помечена `*` |
| `git add <файл>` / `git add .` | добавить в индекс один файл / все изменения |
| `git commit -m "текст"` | зафиксировать проиндексированные изменения с сообщением |
| `git log --oneline` | краткая история коммитов |
| `git diff` | показать ещё не проиндексированные изменения |
| `git push -u origin lab1` | первая отправка ветки и привязка её к удалённой |
| `git push` | отправка новых коммитов в уже привязанную ветку |
| `git pull` | забрать изменения с сервера и слить их с локальной веткой |

Файл `.gitignore` перечисляет пути, которые Git не должен отслеживать. В этом
проекте туда внесены виртуальное окружение, настройки редактора и кэш
